# Reporting a security issue

Use [GitHub's private vulnerability reporting form](https://github.com/Qouve/PureMirror/security/advisories/new) to report a suspected security vulnerability. Reports are submitted privately to the maintainers, rather than as public issues. A GitHub account is required.

You can also email [security@puremirror.dev](mailto:security@puremirror.dev), including if you do not have a GitHub account. Do not open a public issue with vulnerability details.

Describe the affected feature/version, what you observed and the minimum steps needed to reproduce it. Do not include credentials, unnecessary personal information or data belonging to other users. Stop testing if you encounter other users' private data and explain the observation privately.

No reward, response deadline or authorization to access other users' data is implied by this policy.

## Private support

For account problems, privacy requests and content reports, email [security@puremirror.dev](mailto:security@puremirror.dev). A GitHub account is not required. Keep personal information out of public issues; the vulnerability reporting form is for security vulnerabilities.
