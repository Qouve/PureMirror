# PureMirror feedback

Use this repository to report reproducible bugs and suggest improvements to the PureMirror website and overlay. The source code is maintained separately and is not published in this repository.

- Search existing issues before opening a new one.
- Include the affected area and version, steps to reproduce, and expected and actual behavior.
- For a third-party plugin, its own project or author may be the appropriate contact.
- Do not post access tokens, personal account information, private files or unredacted logs. Check screenshots and attachments before sending them.

Report security vulnerabilities through [GitHub's private reporting form](https://github.com/Qouve/PureMirror/security/advisories/new) or email [security@puremirror.dev](mailto:security@puremirror.dev). See our [security policy](SECURITY.md) for guidance. Ordinary issues here are public.

For account problems, privacy requests and reports about unlawful content, email [security@puremirror.dev](mailto:security@puremirror.dev). A GitHub account is not required to contact us by email.

Support is provided as capacity permits; there is no fixed response-time commitment. Please be respectful, keep reports relevant and do not harass other participants. Maintainers may remove sensitive or abusive material and close duplicate or unrelated issues.

PureMirror is an independent, fan-made project. It is not affiliated with, endorsed by, or sponsored by the developers or publishers of the games it references. Game names, trademarks, logos and artwork belong to their respective owners.
